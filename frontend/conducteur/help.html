Guide du conducteur

Comment publier un trajet ?

Cliquez sur « Créer un trajet » dans le menu. Remplissez le point de départ, la destination, la date, l'heure, le prix, le nombre de places et une description optionnelle. Publiez, les passagers peuvent immédiatement réserver.

Accepter ou refuser une demande ?

Rendez-vous dans « Demandes reçues ». Pour chaque demande, cliquez sur Accepter ou Refuser. Les passagers acceptés sont automatiquement ajoutés au groupe du trajet.

Comment modifier le prix d'un trajet ?

Depuis votre tableau de bord, cliquez sur le trajet concerné puis sur « Modifier ». Vous pouvez ajuster le prix tant qu'aucun passager n'a encore réservé.

Quand marquer un trajet comme terminé ?

À la fin du trajet, marquez-le comme terminé. Cela déclenche automatiquement une invitation aux passagers pour vous évaluer et met à jour votre note moyenne.

Comment améliorer ma note moyenne ?

Ponctualité, véhicule propre, courtoisie, communication claire, respect du code de la route.
